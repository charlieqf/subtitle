长素材由同一采访循环构造，视频容器时长 599.036 秒，源文件不足 2 GB，用于接近 10 分钟的大小、上传和时间轴测试，不能当作新增独立医学样本。48 kbps 有一处“围绝经期”转成“危绝经期”；64 kbps 在本次运行中恢复正确，因此默认采用 64 kbps。其 10 分钟目标约为 4.8 MB；工具还会检查成品真实字节数。

审定 TXT 含人工改写，与之逐字编辑距离：FLAC 120、48 kbps MP3 125、64 kbps MP3 124（基准 1,120 字）。这些差异不能全部视为听写错误，也不足以据此断言压缩后全文质量完全不变。

证据：[48 kbps](../evidence/client-handoff-20261109/asr-mp3-48k-verification.json)、[64 kbps](../evidence/client-handoff-20261109/asr-mp3-64k-verification.json)。

## 同步验证

MP3 保留 Xing/gapless 信息，文件首个解码 PTS 为 69.0625 ms；它不是应额外补偿的视频偏移。源音频与 MP3 在 10、120、220 秒，以及长素材的 10、300、580 秒取对应波形窗口，相关性峰值的延迟全部为 **0 样本**。

64 kbps 与 FLAC 的 630 个匹配词、1,260 个起止边界：带符号差异中位数 0 ms，绝对差异 P95 0 ms，最大 100 ms。长素材首轮与短 MP3 的 632 个匹配词，P95 0 ms、最大 50 ms。长素材识别最后一个词结束于 598.875 秒，导出没有超出媒体时长。

循环拼接素材的重采样末端有 28 个采样点（1.75 ms）长度差，10/300/580 秒窗口均无位移；记录在证据中，不解释为整段编码延迟。另用非零音轨起点的合成 MP4 验证偏移映射，用单元测试验证重复导入不累加偏移。未制作人工逐词时间轴基准，本报告不声称绝对同步误差为 0。
